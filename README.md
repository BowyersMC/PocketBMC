# PocketBMC
BowyersMCの一部キャラコンと一部特殊要素をを実装したビヘイビアーパック。  
基本的なものから詳細な点まで自由に設定できるようにしています。

## ❏ 機能
#### ▫ 能動的なキャラコン
- [x] 壁ジャンプ (WallBounce)
- [x] ファストストレート (FastStraight)
- [x] 空屈折 (AirRefraction)

#### ▫ 受動的なキャラコン
- [x] アップドラフト (Updraft)
- [x] エアカーブ (AirCurve)

#### ▫ ユーティリティ
- [ ] 矢で壊せる色付き板ガラス
  - 破壊後、60秒後に修復される仕様での実装を検討
  - 種類は空色板ガラスのみ
- [ ] 任意のエフェクト有無による能動的なキャラコン制限
  - デバフくらっているときに壁ジャンプなどをできなくする仕様

## ❏ 導入方法
1. Releasesより最新の*.mcpackをダウンロード
1. Minecraftを開かずに、*.mcpackをダブルクリックしてインポート
1. 追加したいワールドの編集ボタンをクリック
1. 必要な方はここで念のためワールドのバックアップを複製で取っておいてください
1. 左のメニューの「実験的機能/Experimental」をクリック
1. 「ベータAPI」を有効化
1. ビヘイビアーパック項目から「PocketBMC」を認証

<br />
&nbsp;

## ❏ 設定方法
1. クリエイティブに変更
1. ネザースターをホットバーに追加
1. ネザースターを右クリック
1. UIの指示に従って設定

※設定はOperatorのみ可能です
