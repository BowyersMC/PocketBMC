# PocketBMC
BowyersMCの一部キャラコンと一部特殊要素をを実装したビヘイビアーパック。  
基本的なものから詳細な点まで自由に設定できるようにしています。

## ❏ 機能
#### ▫ 能動的なキャラコン
- [x] 壁ジャンプ (WallBounce)
  - [x] 設定可能な任意のエフェクト有無による発動制限
- [x] ファストストレート (FastStraight)
- [x] 空屈折 (AirRefraction)

#### ▫ 受動的なキャラコン
- [x] アップドラフト (Updraft)
- [x] エアカーブ (AirCurve)
  - モーション付与の仕様により、カクついてしまう為注意

#### ▫ ユーティリティ
- [x] 矢で壊せる色付き板ガラス
  - 破壊後、設定したティック数後に修復される特殊仕様
  - 種類を任意に設定可能 (glass_paneのみ)
- [ ] 鎧の概念
  - [x] 鎧別の被弾可能回数 (-1で無制限化)
    - [x] 革
    - [x] 金
    - [x] 銅
    - [x] チェーンメイル
    - [x] 鉄
    - [x] ダイヤモンド
    - [x] ネザライト
  - [x] 鎧の音声
    - 可否設定
      - [x] 右クリックで装着した時の音声
      - [x] 鎧が破壊された時、破壊した時の音声
    - サウンド定義の設定
      - [x] 装備した時のサウンド
      - [x] 破壊した時のサウンド
  - [ ] パーティクル
    - [ ] 可否設定
- [ ] 特殊速度 (BMCの速度倍率)

#### ▫ イミテイターウェポン
- [ ] Airride
- [ ] Bastet
- [ ] Canopy
- [ ] Doping
- [ ] Leaper

## ❏ 導入方法
1. Releasesより最新の*.mcpackをダウンロード
1. Minecraftを開かずに、*.mcpackをダブルクリックしてインポート
1. 追加したいワールドの編集ボタンをクリック
1. 必要な方はここで念のためワールドのバックアップを複製で取っておいてください
1. 左のメニューの「実験的機能/Experimental」をクリック
1. 「ベータAPI」を有効化
1. ビヘイビアーパック項目から「PocketBMC」を認証

<br />
&nbsp;

## ❏ 設定方法
1. クリエイティブに変更
1. ネザースターをホットバーに追加
1. ネザースターをスニークしながら右クリックでユーティリティ設定を開く
1. ネザースターを右クリックでキャラコン設定を開く
1. UIの指示に従って設定

※設定はOperatorのみ可能です
